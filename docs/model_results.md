# Model Evaluation Summary

The honest model evaluation used a Random Forest classifier.

## Holdout Performance

- Accuracy: 0.5982
- Precision: 0.6183
- Recall: 0.8528
- F1: 0.7169
- ROC-AUC: 0.5914

## Group-Aware Cross-Validation

- Accuracy mean: 0.6102
- Precision mean: 0.6291
- Recall mean: 0.8910
- F1 mean: 0.7373
- ROC-AUC mean: 0.5801

The group-aware results are treated as more realistic because observations from the same farm are kept together.
